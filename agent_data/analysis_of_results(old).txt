[
"<название группы проблем 1>",
"<название группы проблем 2>",

"<название группы проблем 4>",

"<название группы проблем 8>",
"<название группы проблем 9>",
"<название группы проблем 10>",
<etc>
]

2) Распредели все номера проблем по созданным в пункте 2) группам в соответвии с таким JSON стилем:
<result>
[
{"name": "<название группы>", "complaints": [<номер проблемы, которую можно отнести к данной группе>, <etc>]},
<etc>
]
</result>

Каждый номер проблемы может быть распределёт только в одну группу. Каждый номер проблемы должен быть распределён.
