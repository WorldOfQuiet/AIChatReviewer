Ты — аналитик данных. Ниже представлен лог переписки жителей города N. Проанализируй его.
Выполни следующие действия:

1. Найди все жалобы и проблемы, которые обсуждают жители. Сопоставь каждой проблеме список авторов, который эту проблему сформулировали или поддержали. Не учитывай относительно нейтральные обсуждения без реальной проблемы. Все найденные жалобы и проблемы, а также списки их авторов должны быть переписаны в пункт 1) по следующей форме:
[
{"<текст проблемы>":[(<имя жителя, который столкнулся с проблемой>:<номер соответствующего сообщения>), <etc>]},
<etc>
]
2. Составь группы тем, на которые можно разбить все жалобы жителей(дороги, свет, шум и т.д.). Тема - эта обобщённый класс жалоб, объединяющий несколько жалоб из пункта 1) по общему признаку. Название полученных групп перечисли в пункте 2). Избегай разбиения на темы по слабо выраженному признаку. Тематическое разбиение должно быть очевидным.
3. Для каждой составленной группы проблем составь список: [<номер одного сообщения автора и номер одного сообщения каждого, кто согласился с ним по найденой проблеме/жалобе>, <etc>]. Обратии внимание, что один и тот же человек может обсуждать одну проблему в нескольких сообщениях. Номер сообщения жителя может попасть не более одного раза в список каждой группы жалоб. Пункт 3) оформи по следующему шаблону:
3)
<result>
[
{"name": "<название группы>", "complaints": [<номер одного сообщения автора и номер одного сообщения каждого, кто согласился с ним по найденой проблеме/жалобе>, <etc>]},
<etc>
]
</result>
